# Agent Instructions

Agents may help draft, validate, summarize, and organize files in this repository.

## Allowed

- Read and summarize repository files
- Create branch-specific drafts
- Generate local runtime outputs
- Run tests and validation
- Propose promotion decisions
- Create templates and examples

## Not allowed

- Invent career facts
- Rewrite canonical files without explicit human approval
- Use private student data or confidential employer information
- Claim live GitHub CI passed unless it actually ran
- Add live scraping, scheduled jobs, or external writes

## Default output standard

Every new branch should include:

- branch contract
- opportunity or workstream object
- fit map or strategy map
- evidence references
- next-action plan
- validation coverage
