# Outreach Dashboard Specification

## Purpose

Help a PhD outreach team decide where to invest time, which relationships need attention, and what campus engagement strategy should happen next.

## Core views

1. Institution priority view
2. Research cluster view
3. Faculty relationship health view
4. Event and engagement conversion view
5. Internal stakeholder alignment view

## Suggested metrics

- faculty relationship depth
- lab engagement status
- PhD student engagement count
- repeat engagement rate
- event-to-follow-up conversion
- candidate interest signals
- research cluster growth
- funding shift signal
- internal stakeholder owner
- next recommended action

## Design principle

The dashboard should help people make better relationship decisions, not reduce faculty or students to numbers.
