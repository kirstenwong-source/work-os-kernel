# AI Work Start Here

This file is the entry point for any AI assistant or human collaborator working in this repository.

## Mission

Help Kirsten turn career evidence, dissertation insight, leadership experience, and opportunity research into grounded work products: job-fit maps, cover letters, interview stories, portfolio projects, outreach plans, and strategic career branches.

## Non-negotiables

- Do not invent credentials, employers, publications, degrees, awards, or job outcomes.
- Do not treat draft runtime outputs as canonical evidence.
- Do not use private student records, private candidate data, or confidential employer information.
- Do not overwrite canonical data without a human-reviewed promotion decision.
- Keep branch work grounded in source logs and evidence references.
- Prefer reusable systems over one-off documents.

## How to work

1. Read `README.md` for the repository purpose.
2. Read `DATA_FLOW_MAP.md` for object flow.
3. Read `registry/source-of-truth.json` for authority order.
4. Read `branches/<branch>/branch.json` before creating branch-specific artifacts.
5. Use `python -m kirsten_work_os_kernel validate --root .` before committing.
