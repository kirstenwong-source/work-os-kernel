# Operating System Kernel

## Kernel purpose

The kernel keeps Kirsten's professional work from becoming scattered across one-off resumes, notes, and applications.

It provides reusable structure for:

- identity
- evidence
- claims
- opportunities
- branches
- artifacts
- validation
- future learning

## Kernel principle

Every branch should answer four questions:

1. What workstream is this?
2. What opportunity or goal does it serve?
3. What evidence supports the strategy?
4. What artifacts should be produced next?

## The kernel does not decide alone

The kernel can generate recommendations, packets, briefs, and drafts. It does not make final career decisions. Human review remains the promotion gate.
