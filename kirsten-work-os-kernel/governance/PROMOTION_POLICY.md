# Promotion Policy

A runtime output becomes canonical only after review.

## Promotion path

```text
runtime output
-> review note
-> promotion decision
-> canonical update
```

## Promotion requirements

A promoted item must have:

- a clear source or evidence reference
- a reason for promotion
- a target canonical location
- a human reviewer
- no contradiction with existing canonical profile facts

## Non-promotable items

Do not promote:

- invented credentials
- speculative impact metrics
- confidential data
- unverified employer information
- raw AI output without review
