# Source Policy

## Allowed source types

- resume facts
- cover letters
- job descriptions
- public role descriptions
- dissertation exports approved for career use
- notes created by Kirsten
- synthetic portfolio project data

## Restricted source types

- private student records
- candidate records
- confidential university records
- private employer information
- personally identifiable third-party information not meant for public use

## Rule

When in doubt, summarize at a safe abstraction level or use synthetic data.
